# Supply Chain Analysis (Client Project)

## Project Overview

This project focuses on analyzing supply chain data using Power BI to gain insights into supplier performance, inventory, manufacturing, transportation, and product quality. Interactive dashboards were developed to support business decision-making.

## Dataset

- Source: SQL Database
- Imported into Power BI
- Total tables: 2
- Total Records: 100
