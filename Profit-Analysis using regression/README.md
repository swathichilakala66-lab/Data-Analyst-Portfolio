# Profit Analysis Using Regression

## Project Overview

This project analyzes the relationship between business investments and company profit using regression analysis. An interactive Power BI dashboard was developed to visualize spending patterns and profit trends.

## Dataset

- Source: SQL Database
- Imported into Power BI
- Dataset Size: Approximately 50 records
